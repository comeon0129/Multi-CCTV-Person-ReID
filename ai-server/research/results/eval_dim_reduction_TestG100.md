# PCA+Whitening 차원 축소 — Identifiability 비교

- **데이터셋** : CUHK-SYSU (`TestG100`, 100쿼리)
- **원본 차원** : 2048 (BoT ResNet50 BN-Neck 출력)
- **PCA 참조 샘플** : Train split 3000개 (query/gallery와 ID 미겹침)
- **디바이스** : CUDA
- **측정일** : 2026-07-01 14:19

---

## 1. 방법

- **Origin**: BoT 원본 임베딩, 축소 없음
- **PCA+Whiten**: CUHK-SYSU Train split 특징으로 PCA(whiten=True) fit → query/gallery에 적용 후 L2 재정규화
- query/gallery는 두 조건 모두 **동일** (같은 crop, 같은 원본 특징에서 사영) — 차이는 오직 차원 축소 유무
- 랭킹: 코사인 유사도 내림차순, 지표: CMC(Rank-1/5/10), mAP

## 3. 분석

- **mAP 변화**가 음수(-)면 원본 대비 식별 성능 손실, 무시할 수준(예: 1~2%p 이내)이면 해당 차원까지 축소해도 identifiability를 유지한다고 볼 수 있음.
- **설명된 분산**이 낮은데 mAP 손실이 작다면, 나머지 분산은 신원 구분과 무관한 잡음(조명/포즈/배경)일 가능성이 높음 — 오히려 PCA가 노이즈를 제거해 mAP가 Origin보다 **상승**할 수도 있음.
- **유사도 계산(ms)**은 이번 쿼리 수 기준 참고값. 실제 이득은 갤러리 규모가 커질수록 (예: 전체 DB 대상 검색) 차원에 비례해 커짐.
